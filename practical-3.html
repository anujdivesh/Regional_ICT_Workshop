API Integration

An API is a URL that answers with data instead of a page. Reading one, calling it from a web page, and turning the reply into something a person can use.

Reading a URL

Paste an API address into a browser and you get data, not a page. Every part of it means something: 

https://ocean-obs-api.spc.int/insitu/get_data/station/auasi?limit=1
This partCalledWhat it does
ocean-obs-api.spc.int Host Which service you are asking. Nothing else matters if this is wrong.
/insitu/get_data/station/ Path Which question you are asking it - here, observation data.
auasi Station Which station. This one is Samoa, Auasi.
?limit=1 Query Options, after the ?. This asks for one reading. Join more with &.

The reply is JSON - the same format as the Practical 2 forecast file. Which means the skill is the same one: find the keys you need, ignore the rest.

Station codes that work: auasi (Samoa, Auasi), upol (Samoa, Apia), fong (Tuvalu), viti (Fiji, Suva), tara (Kiribati, Tarawa), luga (Vanuatu, Luganville), lomb (PNG, Manus Is).

Asking the API...

// Packages used: none. fetch is built into every browser.

const stationId = 'auasi'   // change this to another station and reload

// 1. Ask the API for the one most recent reading
const response = await fetch(
  'https://ocean-obs-api.spc.int/insitu/get_data/station/' + stationId + '?limit=1'
)

// 2. A reply arrived - but check it is not an error page before trusting it
if (!response.ok) {
  throw new Error('the server replied ' + response.status)
}

// 3. Read the reply as JSON
const result = await response.json()

// 4. Pick out the parts we want. Tide gauges send newest first, so [0]
//    is the latest reading.
const latest = result.data[0]
const seaLevel = latest['sea_level (m)']

// 5. Put it on the page
document.getElementById('sea-level-widget').textContent =
  result.display_name + ': ' + seaLevel + ' m at ' + latest.time
